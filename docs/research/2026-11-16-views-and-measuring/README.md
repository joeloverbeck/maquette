## How to read it

- **Method.** Three research passes by AI agents on 2026-11-16, each working from pages it opened, and one test run in the same session.
- **Evidence marks.** Each research note tags a finding as read on the page that owns it or taken from a search summary, and labels its own reasoning as inference.
- **Known gaps.**
  - No source gives an anime head's depth as a number.
  - No source measures how drawn three-quarter and side views depart from projection.
  - No Japanese studio source on model sheets was reached.
  - The survey of references looked at seven sources that the agent picked.
  - The accuracy test used clean grey drawings, not published ones.
- **Earlier research.** `docs/research/2026-11-15-feasibility/` holds the report and notes from before the founding.
