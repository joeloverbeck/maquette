# design

Designs made by hand, each tool's source file beside its SVG or PNG export. `docs/foundation/05-code-and-design-tools.md` says which tool makes what.

This is the only folder the VectorCraft and FigCraft servers may write to. Armatures the generator emits are output and do not live here. Reference images never do.

`svg-contract/` holds the probes behind the SVG contract in `docs/foundation/02-first-table.md`: hand-written SVG test inputs, which are not designs, and what VectorCraft made of them.
